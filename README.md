# Yizhong Geng Personal Homepage

Personal academic homepage for Yizhong Geng, adapted from the PRISM template.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static export is generated in `out/`.

## Content

- English content lives in `content/`.
- Chinese localized content lives in `content_zh/`.
- Public paper PDFs live in `public/papers/`.
- Local source documents in `related_data/` are ignored by Git.
